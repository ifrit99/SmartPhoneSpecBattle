# VERIFY（合格条件）

> 「完了」はこのファイルだけが定義する。全部 PASS まで GOAL を閉じない。

## 必須（毎回）

| # | 条件 | コマンド / 確認 | 結果 |
|---|------|-----------------|------|
| 1 | 静的解析エラー0 | `flutter analyze` | PASS / FAIL / SKIP |
| 2 | テスト全パス | `flutter test` | PASS / FAIL / SKIP |

## この GOAL 固有

| # | 条件 | 確認方法 | 結果 |
|---|------|----------|------|
| 3 | （例: 該当ウィジェットの空状態テストが追加されパス） | `flutter test test/presentation/...` | |
| 4 | （任意: ブラウザ/実機で1導線） | 手順を具体的に書く | |

## 停止条件（どれか1つで人間へ戻す）

- 同じエラーが **2回** 連続
- `GOAL.md` の対象範囲外の変更が必要
- 仕様が未決 / 複数解釈が残る
- イテレーション **5回** 超、または明らかに長期化
- `git push` 以外に不可逆操作が必要

## 結果サマリー

- 最終結果: （未実施 / PASS / FAIL / STOP）
- 残リスク: （なければ「なし」）
- 次の人間判断: （なければ「なし」）
