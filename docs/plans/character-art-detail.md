## 要件
ユーザー要求（2026-09-03）: キャラクター詳細画面で、キャラの立ち絵を**大きく**見せてほしい。あわせて**キャラクター紹介（bio）**を表示してほしい。
現状（PR #36 時点、360 幅）: 立ち絵は幅の 35%（≒126px）で、カード内でステータスと同格の大きさに収まっている。紹介文はない。

スコープ: `lib/presentation/screens/character_screen.dart` のレイアウトと、紹介文の静的コピーのみ。バトル・codec・`Character` モデル・ガチャ・ホームは触らない。

## 仕様

### 画面/UI変更（`character_screen.dart`）
- **立ち絵をヒーローにする。** `_buildCharacterCard` の `charSize` を幅基準から**ビューポート高さ基準**へ変える。
  - `heroHeight = (MediaQuery.sizeOf(context).height * 0.42).clamp(240.0, 420.0)`
  - `CharacterPortrait(variant: PortraitVariant.full, height: heroHeight)` に渡す。full は 2:3 なので 360×640 では約 269×179px となり、ページ左右パディング 20px の内側に収まる。立ち絵だけで初期ビューポートの約 42%、名前・属性バッジを含むカード全体で約 60% を占める。ページは引き続き `SingleChildScrollView`。
  - 430×932 では約 391px、横向き（高さ 430）では下限 240px。幅が高さ×2/3 を超えるケースはないためオーバーフローしない。
- **枠・グローは足さない。** 既存のグラデーションカード（属性色 30%→`#1B2838`、1px ボーダー）はそのまま使う。新規の光輪・影・台座・パララックス・タップ拡大は v1 に含めない。
- カード内の構成順は現行どおり: 立ち絵 → 名前 → 属性バッジ＋Lv。カード内パディングも現行の 24px を維持。
- **紹介カードを追加。** ヒーローカードの直下、ステータスカードの前に `_buildBioCard` を置く。
  - 見出し「プロフィール」。既存カードと同じ装飾（`#1B2838`、角丸 16、`Colors.white10` ボーダー、padding 20）。
  - 本文: `TextStyle(color: Colors.white70, fontSize: 14, height: 1.6)`。折り返しあり、行数制限なし。
  - 紹介文が無いキーでは**カードごと省略**する（プレースホルダー文は出さない。`statusEffects` 空時の省略と同じ書き方）。

### ロジック/状態変更
- **bio のキーはポートレートキーそのもの。** `PortraitId.fromCharacter(character).key`（`fire_0` …）を使う。`Character` に `bioId` を足さず、codec も変えない（RFC §7 の導出規則を再利用。URL 対戦の受け手も同じ紹介文を解決できる）。
- **bio は絵から独立して解決する。** 画像側の `resolveShippedKey` は `{element}_0`（指揮官）へフォールバックするが、bio はフォールバックしない。例: `fire_2`（ブレイズ）は絵が `fire_0`（フレア）で代替表示されても、フレアの紹介文を出してはならない。`fire_2` の bio が無い間は紹介カードを省略する。
- **PNG 欠落時。** `CharacterPortrait` の既存フォールバック（`errorBuilder` → `PixelCharacter` を同サイズで描く）をそのまま使う。bio カードの表示可否は画像の成否に依存しない。スライス1時点では `water_0`〜`dark_0` がマニフェストに載っているが PNG が無いため、この画面では「12×12 ドット絵（大）＋紹介文あり」の組み合わせが実際に発生する。これは想定内。

### 新規ファイル
- `lib/domain/data/character_bios.dart`: `const Map<String, String> characterBios`（キー = ポートレートキー）と `String? characterBioFor(String key)`。Flutter 非依存の静的コピー。`gacha_device_catalog.dart` と同じ層に置く。
