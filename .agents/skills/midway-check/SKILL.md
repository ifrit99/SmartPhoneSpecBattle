# 途中確認
1. 最初に動く・見える一切れができたら、そこで止める（全部作り切らない）。
2. draft PR を出し、本文に次の 2 つを書く。
   - いまの状態（スクショ 1 枚か、変えた流れの小さな図）
   - 決めてほしいこと 1 つ。案は 2 つまで、1 つに「（おすすめ）」を付け、理由を 1 行
3. ユーザーの答えを待つ。答えが付くまで次の一切れに進まない。Cloud Agent ではそこで実行を終え、返事は同じエージェントへの追いメッセージで受ける。
4. 答えを `docs/plans/<件名>.md` の記録欄に 1 行で残してから続ける。計画ファイルが無いときは作らず、PR 本文に 1 行残す。
