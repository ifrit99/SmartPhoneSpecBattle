# URL battle

Friend から自分のキャラ URL を発行するか、受け取った URL を入力して対戦プレビューへ進む。

## Sub-features

- `url-share` は Friend → `URLでシェアする` で対戦 URL が見え、`URLをコピー` できる。
- `url-paste` は Friend → `URLを入力して対戦` で URL を入れ、対戦プレビューへ進む。
- `url-preview` はプレビューから `バトル開始` でフレンド戦に入る。

## How to get to it (user POV)

- タイトルからホームへ（`cpu-battle.md` と同じ。Web は TAP 2 回、同意、初回オンボーディング）。
- ホームの `Friend` を押す。
- 発行する: `URLでシェアする` → `対戦URLを共有` で URL が見える → `URLをコピー`。
- 入力する: `URLを入力して対戦` → `対戦URL / コード` に URL を入れる → `フレンド対戦を読み取る`。
- プレビューの `バトル開始` でフレンド戦へ。クエリ `/?battle=<encoded>` で開いたときはタイトルを飛ばしてプレビューへ行くこともある。

## Driving it with cdp_drive.py

Preconditions:

- `boot-title` が PASS のインスタンス。ホームまで進める状態。
- 入力側は、発行側が作った URL か、テスト用の有効な `battle=` クエリ。壊れたコードでプレビューを省略しない。
- PR-1 の `verify.sh drive` はこの機能を回さない。

- **Open Friend.** ホームで `Friend` を押す。見出し `フレンド対戦` と `URLでシェアする` / `URLを入力して対戦` が見える。
- **Issue URL.** `URLでシェアする` を押す。画面に対戦 URL が見え、`URLをコピー` が押せる。コピー後の案内は `URLをコピーしました！`。
- **Paste URL.** 別プロファイルまたは同じメニューから `URLを入力して対戦` を開き、発行した URL を `対戦URL / コード` に入れる。プレビューに相手キャラが見える。
- **Start.** プレビューの `バトル開始` を押す。フレンド戦のバトル画面へ進む。
- **Proof.** 発行した URL に `battle=` が含まれること、入力側プレビューに相手が見えること、スクリーンショット。ディープリンクだけ通して Friend メニューを飛ばしたことを、メニュー入口の証明にしない。
- **Command.** 未実装。`bash .agents/skills/verify-ssb/helpers/verify.sh drive url-battle` は FAIL にする。

## Gotchas

- **PR-1 では未証明。** このファイルは地図だけ。ドライブを短くして通したことにしない。
- クリップボードが空だと `クリップボードに対戦URLがありません`。入力欄へ直接入れる道を残す。
- 壊れたコードはデコード失敗の文言で止まる。失敗画面をプレビュー成功に数えない。
- `/?battle=` で開くと初回フレーム後にプレビューへ飛ぶ。Friend ボタンの入口とは別の道。両方とも地図にある。片方で通して両方証明したことにしない。
- 同意ダイアログとオンボーディングは CPU バトルと同じ。ホームの `Friend` より前に終わる。
