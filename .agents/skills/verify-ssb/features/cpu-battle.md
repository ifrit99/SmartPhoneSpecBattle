# CPU battle

ホームの「バトル開始」から敵プレビューと戦術を経てオートの CPU 戦へ入り、リザルトで勝利または敗北が出る。

## Sub-features

- `cpu-open` はタイトルからホームへ行き、「バトル開始」が見える。
- `cpu-preview` は敵プレビューシートで戦術（バランス / オーバークロック / ファイアウォール / バースト）を選べる。
- `cpu-fight` は「バトル！」でオートバトルが始まり、リザルトに `勝利！` または `敗北…` が出る。

## How to get to it (user POV)

- タイトルの `TAP TO START` を押す（Web は 1 回目が音声解除、2 回目で進む）。
- 未回答なら「プレイデータ送信へのご協力」で `協力しない` または `協力する`。
- 初回ならオンボーディング。`スキップ` または `次へ` を 2 回のあと `はじめる！`。
- ホームで `バトル開始` を押す。
- 敵プレビューで戦術を選び `バトル！` を押す。
- バトルはオート。ユーザーが触れるのはスキップだけ。終わるまで待つ。

## Driving it with cdp_drive.py

Preconditions:

- `boot-title` が PASS のインスタンス。空のプロファイル（初回オンボーディングあり）。
- PR-1 の `verify.sh drive` はこの機能を回さない。

- **Reach home.** `TAP TO START` を 2 回掴んで押す。同意ダイアログがあれば `協力しない`。オンボーディングがあれば `スキップ`。ホームに `バトル開始` が見える。
- **Open preview.** `バトル開始` を押す。シートに戦術ラベルと `バトル！` が見える。
- **Start fight.** 推奨または `バランス` を選び `バトル！` を押す。バトル画面へ進む。
- **Wait for result.** リザルトに `勝利！` または `敗北…` が出るまで待つ（上限 50 ターン。壁時計の短いタイムアウトで通したことにしない）。
- **Proof.** リザルトの見出しと、ホームに戻れる `もう一戦` が見えること。スクリーンショットを残す。
- **Command.** 未実装。`bash .agents/skills/verify-ssb/helpers/verify.sh drive cpu-battle` は FAIL にする。

## Gotchas

- **PR-1 では未証明。** このファイルは地図だけ。ドライブを短くして通したことにしない。
- Web のタイトルはタップ 2 回。1 回でホームへ行ったことにしない。
- 同意ダイアログは `barrierDismissible: false`。無視して次へ進めない。
- 初回オンボーディングをスキップせず 3 ページ踏むなら、最後のボタンは `はじめる！`。
- 敵はランダム。勝敗を固定しない。どちらの見出しでもリザルトに着いたことを証明にする。
- バトルは数十秒かかることがある。待ち時間を短くしてスキップしない。
